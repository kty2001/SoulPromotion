# SoulPromotion

체스를 소재로 한 소울라이크 게임 프로젝트.

## 개요

흰색 폰이 **프로모션**을 위해 여행을 떠나는 이야기.
여정 중 흑색 진영의 각 기물을 다스리는 왕들을 쓰러뜨리고, 쓰러뜨릴 때마다 그 능력을 흡수하여 성장함.
최종 목표는 흑색 왕들의 왕, **King of King** 처치.

## 핵심 콘셉트

| 요소 | 내용 |
| --- | --- |
| 주인공 | 흰색 폰 (White Pawn) |
| 목적 | 프로모션을 향한 여정 |
| 보스 | 흑색 기물의 왕들 — King of Pawn, King of Rook 등 |
| 성장 | 보스 처치 시 해당 보스의 능력 흡수 |
| 최종 보스 | King of King (흑색 왕의 왕) |
| 장르 | 소울라이크 |
